#MediGuard - Unified Pharmaceutical Inventory Control System

**A database-driven medicine inventory management system built using Oracle Database, SQL, and PL/SQL.**

MediGuard is designed to manage medicine records, suppliers, stock batches, inventory transactions, and expiry-related information. Its database component uses PL/SQL procedures, functions, and triggers to support inventory operations and reporting.

## 📌 Project Overview

Medicine inventory requires accurate stock records, batch tracking, and expiry monitoring. MediGuard provides a structured database solution to organize this information and support routine inventory operations.

The project demonstrates practical applications of relational database design, SQL queries, stored procedures, functions, triggers, and database auditing.

## ✨ Key Features

- **Medicine Management:** Maintain medicine information.
- **Supplier Management:** Organize supplier records.
- **Batch Management:** Store batch details, quantities, and expiry dates.
- **Stock Receiving:** Support incoming stock operations.
- **Stock Issuing:** Support outgoing stock operations.
- **Expiry Calculation:** Calculate the days remaining until expiry.
- **Low-Stock Reporting:** Identify medicines that meet the configured low-stock criteria.
- **Stock Transaction Logging:** Maintain records of stock movements.
- **Audit Logging:** Record relevant batch-related database changes.
